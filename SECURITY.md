# Security & Privacy

This repository is a sanitized portfolio snapshot.

The original development archive contained authenticated session material and production data. The public version intentionally excludes:

- OptionStrat account credentials
- browser cookies and Playwright storage state
- session metadata
- populated SQLite databases
- captured flow history
- raw failed-response payloads

Use the code only with accounts and data you are authorized to access. Keep `.env`, `session/`, and `data/` out of version control.
